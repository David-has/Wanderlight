# Travel Landing Page

A modern and responsive travel landing page built with HTML, CSS, and JavaScript. Featuring dynamic dark and light themes, immersive nighttime cityscapes, and beautiful sunny beach destinations.

## Features

- Dark and Light Mode
- Modern and responsive design
- Immersive travel visuals
- Smooth animations and transitions
- Interactive UI elements
- Clean and intuitive navigation

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```text
travel-landing-page/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Launch `index.html` in your browser.

## Purpose

This project was created to explore modern front-end development, responsive design, theme switching, and interactive user experiences.
